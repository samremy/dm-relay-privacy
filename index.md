# Privacy Policy for dm-relay

Last updated: 21/10/2026

dm-relay is a personal, non-commercial tool operated by Samuel Baker. It
forwards direct messages received by one Instagram professional account,
owned by the operator, to the operator's own phone as push notifications.
It is not offered to the public and has no other users.

## What data is processed

When someone sends a direct message to the connected Instagram account,
Meta sends the app a notification containing the sender's Instagram-scoped
ID and the content of the event (message text, a link to a shared reel or
post, or a reaction).

## How it is used

The data is used only to create a push notification for the account owner.
It is sent through the ntfy notification service (ntfy.sh) to the owner's
device. It is not used for advertising, analytics, profiling, or any other
purpose, and it is not sold or shared with anyone else.

## Storage

The app does not store messages in a database. Data is processed in memory
and discarded after the notification is sent. The hosting provider (Render)
may keep standard server logs for a limited time.

## Third parties

- Meta/Instagram, which delivers the webhook notifications.
- ntfy.sh, which relays the notification to the owner's device.
- Render, which hosts the server.

Each of these has its own privacy policy.

## Your choices and data deletion

Because the app does not retain message content, there is no stored data to
delete. If you sent a message to the connected account and have questions
or want to ask about any data, contact @samb_msg on Instagram.
